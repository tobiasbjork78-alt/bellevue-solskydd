## Särdrag

- Pagunette erbjuder textilier med ljusäkthetsinformation enligt ISO 105-B02 (skala 1–8, där 8 är högst motstånd mot blekning). Information om ljusäkthet finns på hemsidan för de flesta textilier.  _(källa: pagunette.se)_
- Gardiner kan fodras för att skydda textilier från att blekna — de fodrade lagren fungerar som en barriär som absorberar eller reflekterar en stor del av solljusets energi, vilket hjälper till att bibehålla färgernas intensitet.  _(källa: pagunette.se)_
- Pagunette tillverkar liftgardiner som kan monteras i vägg eller tak, med antingen ändlös kedja eller snördrag som manövreringsmekanism.  _(källa: pagunette.no)_
- Pagunettes produktkategorier inkluderar bl.a. lysdämpande metervarer, gardintillbehör, mönstrade och enfärgade textilier, extra breda textilier och slitstarka tyger med Martindale-klassning.  _(källa: pagunette.dk)_
- Plain Wool-textilen (exempel på Pagunette-metervara) har komposition 70% WOOL / 30% PES (100% RECYCLED WOOL), egenskaper Akustik, Flammehæmmende (FR), Recycled, Martindale 60.000, ljusäkthet ISO 105 B02 SCALE 5 (1-8), och certifiering enligt Global Recycled Standard (GRS).  _(källa: b2b.pagunette.dk)_

## Begränsningar och negativ info


## Begränsningar

- Alla gardiner som utsätts för solljus kommer att blekna med tiden — även med hög ljusäkthet. Naturfibrer som bomull, linne och siden är särskilt känsliga för blekning.  _(källa: pagunette.se)_
- Vissa färger är mer mottagliga för nyansförändringar — t.ex. om det gula färgämnet bleknar snabbare än det blå skiftar nyansen mot blått. Röd färg kan utveckla en mer orange eller rosa nyans med tiden.  _(källa: pagunette.se)_
- Övergång till mer hållbara och miljövänliga färgningsmetoder kan innebära att moderna textilier bleknar lättare jämfört med äldre textilier som använde mer kemikalier.  _(källa: pagunette.se)_

## Vanliga problem

- Liftgardiner: snören kan ibland 'hoppa' ut ur det lilla hålet i spolarna, vilket ger problem med gardinens funktion. Kontrollera att snören sitter korrekt i spolarna.  _(källa: pagunette.no)_

## Olämpliga lägen

- Tjocka gardiner framför akustisk dämpning kan påverka dämpningens effekt negativt — tunna, genomsläppliga tyger rekommenderas istället.  _(källa: faktiskt.io)_

## Återförsäljarkunskap


## Praktiska tips

- Variera vikningen av gardiner regelbundet för att undvika fasta veck som ger ojämn blekning och tydliga bleka ränder med tiden.  _(källa: pagunette.se)_
- Fodra gardiner för att skydda mot UV-blekning — fodringslagren fungerar som barriär som absorberar/reflekterar solljusets energi.  _(källa: pagunette.se)_
- Vid montering av liftgardin: lossa stoffet från kardborrband för att göra monteringen enklare. Skruvar medföljer inte — olika underlag kräver olika skruvar, använd skruvar med platt huvud.  _(källa: pagunette.no)_
- Andningstestet för tyg framför akustikdämpning: 'Kan man andas så är det ok går det trögt så är det mindra lämpligt' — dvs. gardintyget bör vara tillräckligt genomsläppligt.  _(källa: faktiskt.io)_

## Monteringskunskap

- Liftgardin med ändlös kedja: montera medföljande beslag i vägg eller tak. Fäst gardinens främre spor till beslaget, tryck gardinen in och vipp upp bakifrån så att bakre hakarna klickar fast. Fäst sedan tyget på kardborrbandet.  _(källa: pagunette.no)_
- Liftgardin med snördrag: montera beslag med tappen pekande nedåt. För gardinens spor in så att tappens huvud sitter i sporet, vrid sedan tappen uppåt för att låsa gardinen.  _(källa: pagunette.no)_
- Felsökning: om liftgardinen inte fungerar, kontrollera att snören sitter korrekt i spolarna — snören kan ha hoppat ur det lilla hålet.  _(källa: pagunette.no)_
